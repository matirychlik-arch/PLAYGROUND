# Template and plan format

`template/timeline.json` is generated by `scripts/dev/build_template.py` (the reference edit rebuilt frame by
frame: `the_dusk_boy_many_lies_motion_v2.mp4`, 366 frames, 160 BPM = 9 frames per beat, frame 0 = the drop).

## Template
- `slots`: `{name: {kind, note}}`. Kinds: eyes, face, hero, profile, medium, walk, wide, detail, back, bright.
- `shots`: contiguous `[f0, f1)`; footage shots carry `slot`, `off` (frames into the slot window), `g`
  (`bw` | `color` | `pop` | `orig`), `zr` ([start, end] zoom relative to the slot camera) and effects:
  `flash` (per-frame list), `punch`, `glitch` (shot frame indices), `neg`, `fi`/`fo`, `gamma`, `echo`,
  `knock` ({lines: [[text, size]], bg}), `mir`. Other shots: `{solid: 0..1}`, `{collage: [panel..], bg}`.
- panels: `{slot, off, rect: [x, y, w, h], at, rate, g, border, rot, shadow}`.
- `ev`: overlay events `{type, f0, f1, ...}`: word, marquee, lower, labels, stack, kinetic, cutouts, frame,
  counter, leak, slices, wipe, shake (parameters as in `engine/fx.js` EVH.*).
- `rgb` `{frame: px}`, `scan` `[[f0, f1]]`, `qa_frames`, `music`.

## Plan (`<job>/web/plan.json`, engine input)
Same shots/events with slots resolved: footage shots get `src: "v0"`, `sf` (first source frame), `cx`, `cy`
(source px), `z0`, `z1`; panels get `src`, `sf`, `cx`, `cy`, `z`. `src.v0 = {n, w, h, dir}`.
`engine/index.html?render=1&from=A&to=B` renders frames, `?sheet=f1,f2&cols=6&div=3&name=N` stills, no query =
interactive preview (`ML serve`).

## Changing the template
Edit `scripts/dev/build_template.py`, run `python3 scripts/dev/build_template.py <reference.mp4>` (refreshes the
QA reference frames too), then re-run `ML edit` + `ML render` on a test job and compare `qa/cmp_*.jpg`.
