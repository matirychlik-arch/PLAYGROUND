edit) `huntress_overlay_edit.mp4` (11.8 s, 354 frames, 30 fps, 1920x1080) and its handoff (cut table, panel geometry
measured on the frames, effect settings of the original numpy renderer). Never hand-edit the JSON.

## Template
- `slots{name: {kind, note, group}}`: kinds are explained in `scripts/edit.py`; `group` = panels that must differ
  from each other but may reuse full-frame moments (cas1, cas2, pops, runpops, finale).
- `items{id: {slot, f0, n, off, speed, zr, aspect, dw, look, expo}}`: a placement shows slot frames
  `off + round(k * speed)` at output frames `f0 + k`; `zr` = zoom ramp relative to the slot camera; `aspect` = crop
  aspect (16:9, 2.4 for cascade / pop panels, ~0.92 for split strips); `dw` = widest display width (fraction of W).
- `segs[{f0, f1, base, layers, fx, trk}]`, contiguous:
  - `base`: `solid {v}`, `item {id}`, `sil {id}`, `cosmic {id}`, `echo {id, from, taps, w}`, `wipe {a, b, p}`.
  - `layers`: `{id, from, until?, rect: [x0, y0, x1, y1]}` (normalized) or `{id, from, scale: {frame: s}}` (centred).
  - `fx` (`at: base` = before the layers, else after): spark, cosmic, burst, zblur, noise, glitch, hlkeep, bloom,
    mblur, leak, fade; per-frame values in `v: {frame: value}` or a range `f0`/`f1`.
  - `trk`: `{id, item, f0, f1, np, labels, arcs, circles, dots, nlab}` tracking overlay on an item.
- `caps[[f0, f1, word]]`, `sfx[[item, f0, f1, gain]]` (which item's own sound plays when), `qa_frames`, `music`,
  `music_note`, `sfx_default` (false: the clip sound is mixed only with `--sfx`).

## Plan (`<job>/web/plan.json`, engine input)
Template segments + `items` resolved by `edit.py`: `{slot, f0, n, k0, speed, aspect, c0: [cx, cy, z], c1, look,
expo, sharp}` (source px of `shots/v0.mp4`, z = 1 is the 16:9 cover crop); `crops{slot: {dir, sf, n, box, ew, eh}}`
(frames cut by `pb.py` into `web/crops/<slot>/`), `tracks{id: {f0, pts}}` (per output frame, source px),
`sil{mode, hint}`, `src{w, h}`. `engine/index.html?render=1&from=A&to=B` renders frames, `?sheet=f1,f2&cols=6&div=5&name=N`
stills, no query = interactive preview (`PB serve`).

## Changing the template
Edit `scripts/dev/build_template.py`, run `python3 scripts/dev/build_template.py <reference.mp4>` (refreshes the QA
reference frames too), then `PB edit` + `PB render` on a test job and compare `qa/cmp_*.jpg`.
Binary assets (music + QA frames) ship as one CDN archive: after changing them run
`python3 scripts/dev/pack_assets.py pack <out.tar.gz>`, upload it, then `pack_assets.py manifest <out.tar.gz> --url
<cdn url> --media-id <id>` and copy the new `assets.json` into the workflow bundle.
