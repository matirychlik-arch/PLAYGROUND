## How to read an entry

Each line is `**Name**: description`. The description text is the original catalog wording, unedited. Use it as the effect brief: the first sentence is the visible effect, the "Built for" sentence is the intended use. Names are the original effect names, so they can be matched one to one with an effects gallery in a tool that ships the same list. Group notes in italics are craft guidance added for this library.

## Pairing hints

- Hook (group 1) into transition (group 3) into product reveal (group 5) is the standard three-clip hook sequence; see SKILL.md.
- Surreal time effects (Act natural, Frozen in motion, Stop world) pair with any group 3 transition because the frozen frame gives a clean handoff.
- Style looks (group 7) go last in the chain, applied to the finished cut, never between clips.
