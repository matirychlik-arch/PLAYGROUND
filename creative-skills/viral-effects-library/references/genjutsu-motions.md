## The two operations

- **motion_transfer**: copy actions, gestures, dance or camera motion from a driving video onto the subject in your reference image. Inputs: one driving video plus one or more reference images. The result keeps the driving video's choreography and camera, with your subject and (usually) your reference look.
- **object_replacement**: replace, change or swap an object, product, garment or character inside a source video using reference images. Inputs: one source video plus reference images. The result keeps the source scene and replaces the named target.

Choose by what the user asks for, not by the example's label: an example listed as object replacement can be used to copy its actions or camera, and the reverse. In prompt terms: "copy the movement" means motion transfer; "swap X for Y in this clip" means object replacement (see video-edit-prompting for the grammar).

## How to use a preset name

Every item in the three source galleries carries the same description: a motion-transfer or object-replacement reference with a driving video. The galleries contain no per-preset prompt text, only the name, the mode and the driving clip. So treat each name as a pointer to a kind of source clip and a kind of operation:

1. Find a name close to the clip you want to imitate (a dance, a runway walk, a car orbit, a pet performance).
2. In a tool that ships the same gallery, select the preset and add your own reference image; never reuse the example's character.
3. In any other tool, recreate the idea: take or find a driving clip with that kind of motion, then write the transfer or replacement prompt with the grammar in video-edit-prompting.
4. Use your own reference images for the subject, and match the reference framing to the driving clip (a full-body reference for full-body motion, a close portrait for a talking-head clip); mismatched framing is the usual cause of drifting faces and limbs.
