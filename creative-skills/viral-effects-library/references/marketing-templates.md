## What these lists are

Names and types only (the source returned no prompt text). Use them as a vocabulary of looks: a name like "Liquid Gold" or "Signal Red HUD" is a ready-made art-direction phrase you can put into a generator prompt. Types: 2d_motion = flat animated graphics; saas_motion = clean UI/app-style motion; hypermotion = fast, high-energy product motion; mixed_media = collage of photo plus graphic elements. For product shots, product_shots = product alone, product_shots_people = product with a person.

## Using a name as a style anchor

- Pick the type first (hypermotion for a punchy product ad, mixed_media for a collage-style hook, saas_motion for app or software promos, 2d_motion for explainer-style graphics).
- Put the name in the prompt as a look reference and describe it in your own words in the same sentence (for example: "Candy Color Swap style: product on a saturated flat color, color flips to the next flavor on each beat"). A bare name is a hint, not a spec, outside the tool that owns the template.
- For people-with-product shots, the "_people" names read as scene descriptions (Spa Morning, Street Skate, Workout Mat): copy the scene, not the exact framing.
