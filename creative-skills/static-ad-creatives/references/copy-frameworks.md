## 1. Provenance

Hook angles, the objective list, the creative fields (headline, primary text, CTA, destination URL), the "use the user's own words, never invent selling points" rule and the default 5-variant pack come from the source ad workflows. The named frameworks (AIDA, PAS, BAB, FAB, 4U), the length limits and the Polish notes are standard direct-response practice added here; platform limits change, so confirm them in the ads manager before a large run.

## 2. Ad anatomy

Each creative carries these fields:

| Field | Where it appears | Job |
|---|---|---|
| Headline | on the image and/or the ad headline field | stop the scroll, state the one promise |
| Primary text | above the image in the feed | develop the promise, add proof, give the reason to act |
| CTA | button label (and a short line on the image) | the single next step, matched to the objective |
| Description | below the headline in some placements | optional: offer detail, shipping, guarantee |
| Destination URL | the click target | where the CTA goes |

The image and the headline must say the same thing. The image gets the hook in about half a second; the primary text can be read later. One ad, one promise, one CTA.

## 3. Hook angles

Every ad needs a different angle of attack. Use these as variant generators; assign one per creative.

| Angle | Visual approach |
|---|---|
| `problem-solution` | Visualize the pain point or problem state |
| `transformation` | Show the desirable end state |
| `social-proof` | Show product with trust cues, lots of users implied |
| `curiosity-gap` | Intriguing visual that demands explanation |
| `lifestyle-aspiration` | Show the aspirational life the product enables |
| `feature-zoom` | Closeup on a specific differentiating feature |
| `comparison` | Side-by-side or before-after style |
| `urgency-scarcity` | Time-limited or limited-availability cue |
| `founder-story` | Personal, founder-led visual |
| `bold-statement` | Strong dramatic visual |
| `unboxing-reveal` | Anticipation and product reveal |
| `behind-scenes` | Process, manufacturing, raw authenticity |

Copy move per angle (headline pattern, to be filled only with true facts):

| Angle | Headline pattern |
|---|---|
| problem-solution | name the pain in the customer's words, then the fix: "<pain>? <product> <fix>." |
| transformation | state the after: "From <before> to <after> in <time>" (time only if true) |
| social-proof | the number or quote the user supplied: "<N> osób już wybrało ..." only with a real N |
| curiosity-gap | a question or unfinished claim the image answers |
| lifestyle-aspiration | the feeling or moment, not the spec |
| feature-zoom | the one feature, in plain words, with its benefit |
| comparison | "<product> vs <the usual way>", a fair contrast, no named competitors without the user's say |
| urgency-scarcity | the real deadline or real stock limit supplied by the user |
| founder-story | first person, one concrete detail |
| bold-statement | one short declarative claim the product can back |
| unboxing-reveal | the anticipation line: "Co jest w środku?" |
| behind-scenes | the process fact: how it is made, with a real detail |

Default 5-variant pack when the user has not specified:
1. `lifestyle-aspiration`, IG Feed (4:5)
2. `feature-zoom`, IG Feed (4:5)
3. `transformation`, IG Story (9:16)
4. `social-proof`, FB Feed (1:1)
5. `curiosity-gap`, IG Story (9:16)

Confirm or modify with the user before generating.

## 4. Objectives and CTA mapping

Set an objective only when the user made the goal clear; otherwise leave it out and let the product profile decide.

| Objective | Meaning | Leading angles | CTA (en) | CTA (pl) |
|---|---|---|---|---|
| `sales` | purchases | feature-zoom, social-proof, urgency-scarcity, transformation | Shop Now, Order Now, Get Offer | Kup teraz, Zamów teraz, Sprawdź ofertę |
| `leads` | sign-ups, demos, quotes | problem-solution, social-proof, comparison | Sign Up, Get Quote, Book Now | Zapisz się, Poproś o wycenę, Umów się |
| `traffic` | visits, clicks | curiosity-gap, bold-statement, lifestyle-aspiration | Learn More, See More | Dowiedz się więcej, Zobacz więcej |
| `awareness` | a launch, being known | bold-statement, founder-story, behind-scenes, unboxing-reveal | Learn More | Poznaj |
| `engagement` | comments, shares | curiosity-gap, comparison, lifestyle-aspiration | Learn More, Send Message | Napisz do nas |

Use the platform's own CTA button list when the ad has a button (the label must be one the platform offers). The on-image CTA line can be freer but stays short.

## 5. Frameworks

Pick one per creative; keep primary text to the shape of the framework.

**AIDA** (Attention, Interest, Desire, Action): good default for cold audiences.
```text
Attention: <headline, the hook>
Interest: <one concrete fact that makes the promise believable>
Desire: <the benefit in the customer's life>
Action: <CTA with the offer>
```

**PAS** (Problem, Agitate, Solution): for problem-solution and leads.
```text
Problem: <the pain, in the customer's words>
Agitate: <what it costs them if it stays>
Solution: <product as the fix> + <CTA>
```

**BAB** (Before, After, Bridge): for transformation.
```text
Before: <current state>
After: <desired state>
Bridge: <product> + <CTA>
```

**FAB** (Feature, Advantage, Benefit): for feature-zoom and spec-heavy products.
```text
Feature: <what it is>
Advantage: <what it does better>
Benefit: <what the customer gets>
```

**4U** (Useful, Urgent, Unique, Ultra-specific): a check for headlines. Score each 0-2; a headline under 5 of 8 gets rewritten. Urgent only if the urgency is real.

Rules of thumb:
- Lead with the customer's outcome, not the brand name.
- One number beats three adjectives, but only a real number.
- Short sentences. One idea per line. Primary text first line must work alone, since it is what shows before "more".
- Offer line (discount, shipping, guarantee) goes where the eye ends: late in the primary text and in the description.

## 6. Length limits

Platform limits shift; treat these as working defaults and verify in the ads manager.

| Field | Working limit |
|---|---|
| Meta primary text | first ~125 characters show before "more"; keep the hook inside them; total under ~300 for statics |
| Meta headline | ~27-40 characters before truncation on mobile; aim for under 32 |
| Meta description | ~30 characters; often not shown |
| On-image headline | 2-6 words; for the bold overlay style, 2-4 words max |
| On-image CTA line | 1-3 words |
| TikTok ad text | keep under ~100 characters |

Polish runs about 15-20% longer than English; budget for it and check the layout with the real strings.

## 7. Claims and honesty rules

- Use the user's own words for copy fields. Never invent selling points.
- Never invent prices, discounts, deadlines, stock levels, review counts, ratings, "as seen in", certifications, test results or guarantees. If the user did not supply it, it does not appear.
- Health, finance, beauty-result and before/after claims are policy-sensitive on Meta and TikTok: state only what the user can substantiate, avoid implying personal attributes ("Masz cellulit?"), avoid guaranteed outcomes.
- No competitor names unless the user asks and can substantiate the comparison.
- If a framework needs a fact the sheet lacks, leave `[TO CONFIRM: ...]` rather than fill it.

## 8. Polish copy notes

- Decide address once: informal "Ty" (most DTC/social) or formal "Państwo"; keep it consistent across the pack.
- Diacritics (ą ć ę ł ń ó ś ź ż) must render in every font and in generated on-image text; verify each string visually.
- Prefer concrete verbs: "Zamów", "Sprawdź", "Odbierz", "Wypróbuj". Avoid anglicisms when a short Polish word exists, unless the brand uses them.
- Hyphen/line-break traps: avoid single-letter words ending a line (i, o, u, w, z, a); use a non-breaking space after them in Figma.
- Currency and format: "99 zł", "od 99 zł", "-20%"; use "darmowa dostawa" only if true.

## 9. Worked example (illustrative)

Product: reusable steel water bottle, offer 15% off first order (user-supplied). Angle: feature-zoom, 4:5, objective sales.

```text
Headline: "Zimna woda przez 24 godziny"          [only if the user confirmed the 24 h figure]
Primary text:
Podwójne ścianki, które trzymają temperaturę cały dzień.
Pasuje do uchwytu w samochodzie i do plecaka.
-15% na pierwsze zamówienie. Sprawdź ofertę.
CTA button: Kup teraz
```
Structure: FAB (feature: double wall; advantage: holds temperature; benefit: cold water all day) with the offer last. The 24 h figure is a placeholder example; it appears only with a user-confirmed fact.
